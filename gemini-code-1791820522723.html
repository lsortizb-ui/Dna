The Central Dogma of Molecular Biology

DNA Replication, Transcription & Translation

DNA  →  RNA  →  Protein

📍 Objective

Understand how genetic information is copied, read, and expressed into proteins.

1. DNA Replication

Making an exact copy of DNA before cell division.

🧬 Key Enzymes

Helicase: Unzips the double helix.
DNA Polymerase: Adds complementary nucleotides (A-T, C-G).

⚡ Key Feature

Semi-Conservative: Each new DNA molecule contains 1 original strand and 1 new strand.

🌐 Open DNA Replication Simulator

2. Transcription

Copying DNA instructions into mRNA (inside the Nucleus).

📝 Base Pairing Rules

DNA → mRNA
A → U (Uracil)
T → A
C → G | G → C

🎯 Main Goal

Create a messenger RNA (mRNA) copy that can leave the nucleus and head to the ribosome.

DNA Strand:    3' - TAC GGC TTA ACT - 5'
mRNA Strand: 5' - AUG CCG AAU UGA - 3'

3. Translation

Building proteins from mRNA code (at the Ribosome).

🔑 Key Concepts

Codon: 3 bases on mRNA.
Anticodon: 3 matching bases on tRNA carrying an amino acid.

🏁 Start & Stop

AUG: Start Codon (Methionine).
UAA / UAG / UGA: Stop Codons.
